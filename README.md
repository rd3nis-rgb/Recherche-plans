# Catálogo de Planos

Site estático pronto para GitHub Pages.

## Publicar no GitHub

1. Crie um novo repositório no GitHub.
2. Envie todos os ficheiros desta pasta para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.

O site ficará disponível no endereço indicado pelo GitHub Pages.

## Atualizar o catálogo

Substitua o ficheiro `catalogo.json` por uma nova versão que mantenha os mesmos nomes de campos. Não altere o nome do ficheiro.
